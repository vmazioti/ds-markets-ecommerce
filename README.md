# Πληροφοριακά συστήματα
## Εργασία 2 - Πληροφοριακό σύστημα για τα σούπερ μάρκετ DS Markets

## Dockerfile

Αρχικά δημιουργούμε το Dockerfile το οποίο περιέχει ό,τι χρειάζεται το container για να τρέξει.

``` 
FROM python:3.9 **Το container θα τρέχει σε python (προσπάθησα με ubuntu και δεν δούλευε)**
RUN apt-get update  **Θα κάνει update για να είμαστε **
RUN apt-get install -y python3 python3-pip **Θα χρειαστούμε εγκατεστημένη την python3 και το pip για να εκτελούμε εντολές σε αυτήν (ενδεχομένως να μην χρειάζόταν αφού έχει ήδη python το container)**
RUN pip3 install --upgrade pip **Κάνουμε μια ενημέρωση στο pip**
RUN pip3 install flask pymongo **Εγκαθιστούμε τα flask και mongo**
RUN mkdir /app **Δημιουργούμε τον φάκελο app**
RUN mkdir -p /app/data **Δημιουργούμε τον φάκελο data**
COPY main.py /app/main.py **Βάζουμε το app.py στον φάκελο app**
ADD data /app/data **Βάζουμε τα data στον φάκελο data** 
EXPOSE 5000 **Του λέμε ποιο port θα χρησιμοποιεί για να επικοινωνεί το container με τον "έξω" κόσμο**
WORKDIR /app **Ποιον φάκελο θα χρησιμοποιήσει για να τρέξει**
CMD ["python","-u","/app/main.py"] **Δείχνουμε στο cmd οτί θα τρέξει σε python και που είναι και ποιο είναι το όνομα του αρχείου που θα τρέξει. Το -u το προσθέτουμε για να μπορούμε να έχουμε logs ώστε να ξέρουμε αν τρέχει ή όχι**
```
## Πώς τρέχουμε το container

Δημιουργούμε το docker-compose.yml με το οποίο θα μπορούν τα services μας να τρέχουν μέσα στο ίδιο container. Προσθέτουμε την εντολή "restart: always" ούτως ώστε να ξεκινάει ξανά το service σε περίπτωση που πέσει. Με την εντολή "volumes: - ./mongodb/data:/data/db" λέμε να βάζει τα δεδομένα της βάσης δεδομένων στον φάκελο data ετσι ώστε να μην χαθούν εάν σβήσουμε το container. Επίσης σε κάθε service λέμε συγκεκριμένα ποιο port θα χρησιμοποιεί μέσα στο container για να επικοινωνούν μεταξύ τους. 

Για να δημιουργήσουμε το container χρειάζεται να έχουμε στον υπολογιστή μας το docker compose. Σε περιβάλλον windows περιέχεται μέσα στο Docker, διαφορετικά θα πρέπει να το εγκαταστήσουμε. Αφού έχουμε το αρχείο docker-compose.yml θα πλοηγηθούμε στον φάκελο ο οποίος το περιέχει και θα τρέξουμε την εντολή docker compose up -d για να ξεκινήσει να δημιουργεί το container.
